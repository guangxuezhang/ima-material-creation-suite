# 人群树调用规则

本规则供“人群＋大字报＋营销”和“人群＋人物卡片＋大字报＋营销”调用。人群树不是四选一的标签库，而是从宽到窄的四层定位系统。用户只点某一层时，就以该层为 P1 的主要认领对象；用户组合多层时，按 `L1 环境＋L2 身份＋L3 阶段＋L4 处境` 逐步收窄。

## L1｜组织与生活环境：得到母人群

用于大范围覆盖和系列总入口。可选：体制内、企业职场、创业经营、校园学习、求职考试、自由职业与内容创作。

示例指令：“面向人群第一层，生成1篇人群＋大字报营销。”
得到：以“企业职场”“体制内”等母人群为 P1 主语，覆盖面大，具体痛点由物料库补充。

## L2｜具体身份：得到职业/角色人群

用于增强身份认领，适合垂直账号或专题系列。

- 体制内：公务员、事业单位员工、国企员工、学校教师、医院医护、科研院所人员、街道社区工作者、乡镇基层工作人员、公共服务单位人员。
- 企业职场：职场新人、项目经理、产品经理、销售人员、运营人员、人力资源、行政人员、财务人员、技术人员、部门主管、中层管理者。
- 创业经营：创业者、创业公司老板、小微企业老板、个体经营者、生意人、门店经营者、家族企业接班人、团队负责人。
- 校园学习：大学生、研究生、职业学校学生、学生干部、即将毕业的学生、即将进入社会的人。
- 求职考试：考公人群、考编人群、考研人群、应届毕业生、求职者、转行者、职业转型者、暂时失业的人。
- 自由职业与内容创作：自由职业者、内容创作者、自媒体博主、主播、独立咨询师、知识付费从业者、独立开发者、个人创业者。

示例指令：“面向人群第二层的项目经理，生成1篇人群＋人物卡片＋大字报营销。”
得到：P1 直接点名项目经理，正文、任务、模型和产品使用链全部围绕项目推进重写。

## L3｜成长阶段：得到阶段性人群

用于表达“我正处在哪一步、下一步想去哪”，兼顾人群规模与明确欲望。

可选：刚进入行业、工作1—3年、工作3—5年、想晋升、想涨薪、想转岗、想从业务岗走向管理岗、第一次当主管、第一次带团队、第一次负责大型项目、成为部门骨干、进入职业瓶颈期、处于转型期、事业发展停滞、需要重新选择方向。

示例指令：“面向人群第三层的第一次当主管者，生成1篇人群＋大字报营销。”
得到：P1 围绕首次管理的成长欲望，正文必须出现带团队、分工、反馈或资源配置等阶段任务。

## L4｜真实处境：得到高共鸣痛点人群

用于最强点击和转化，把职业名称换成用户正在经历的具体困境。

可选：总被安排杂活、不会向上汇报、经常背锅、做事很多却没有成果、工作努力却不受重视、总抓不住重点、遇复杂问题就慌、不知道领导真正想要什么、不会处理职场关系、不敢拒绝别人、经常被同事拿捏、总在低价值忙碌、想得多行动少、计划总完不成、项目推进不动、团队不服管理、多部门协作困难、创业方向摇摆、资源有限却同时铺太多、被边缘化或长期不得重用。

示例指令：“面向人群第四层中总被安排杂活的人，生成1篇人群＋人物卡片＋大字报营销。”
得到：P1 用具体处境完成认领，正文通过毛选模型解释根因并连接产品使用动作。

## 组合与自动调用

- 只给 L1：系统从该母人群下选择一个近期未重复、证据充分的 L2—L4 组合，但 P1 主语仍保持 L1 的宽度。
- 只给 L2：自动匹配其最常见且有物料证据的 L3 或 L4。
- 只给 L3：跨职业表达阶段欲望；若需更强点击，补一个 L4。
- 只给 L4：以处境为 P1 主语，自动选择最匹配但不过窄的 L1/L2 作为正文背景。
- 同时指定多层：严格使用指定组合，不擅自换人群。
- 同批次去重：人群、时长、微动作、毛选模型、结果承诺至少四项不同；不能只换职业名称。
- “人群＋人物卡片”与“纯人群”共用同一棵树和同一标题正文逻辑，区别只在 P1 是否使用人物卡片视觉容器。
