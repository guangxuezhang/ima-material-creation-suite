# 人群大字报 P1｜版本A原生手写字体规则

用于“人群＋大字报＋营销”和“人群＋人物卡片＋大字报＋营销”的 P1 首图。视觉方向以对标 `XHS-20260808-6A76E845` 原图为准：像用户自己做的读书分享卡片，降低广告感。

## 固定视觉规则

- 采用自然中文手写/马克笔笔触，允许轻微不规整，不使用粗重商业标题字体。
- 主文字以克制的深红色为主，避免大面积红黑交替、渐变、阴影、3D和高光。
- 保留大面积奶油色留白、左侧松散排版、小号开头和结尾引号。
- 人群词下方可使用一条轻微蓝色手绘下划线；不增加图标、产品截图或装饰性插画。
- P1 信息保持四段：人群；真实时间场景＋微动作；“毛选思维”；一个可感知的结果。
- P1 可写得比发布标题完整，但不得堆叠解释性副标题或产品卖点。

## 生成与验收

生图提示必须明确“真人分享感、自然手写、留白、低营销感”；生成后逐字检查人群、时长、“毛选思维”和结果句，发现错字或字体过度商业化不得交付。版本A作为默认风格，除非用户明确指定其他视觉方向。
