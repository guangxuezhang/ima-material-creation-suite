# 飞书自动交付

## 适用模式

营销笔记、大字报＋营销图和漫画笔记生成并通过质检后，默认自动写入以下已配置飞书多维表格；用户明确要求不写入时除外。

目标链接优先读取环境变量 `FEISHU_BASE_URL`；未设置时才使用技能内记录的默认链接：

https://my.feishu.cn/base/DNaSbjHIBaoSkks1OmHc4wjmnme?from=from_copylink

长文笔记不自动套用本规则，除非用户另行授权。

## 字段

每篇只填写：

- 标题；
- 文案；
- 标签；
- 图片。

不得写入产品字段、模板编号、模板来源、对标编号、内部创作说明或长文专属评论区引导。

## 写入规则

- 一篇笔记对应一条记录，全部页面按正确顺序放入图片附件字段。
- 只使用空白记录，不覆盖已有内容；空白记录不足时停止并说明。
- 写入前核验本地图片完整且数量正确。
- 写入后回读记录，核验标题、文案、标签和图片附件均存在，且附件数量与本地一致。
- 批量写入使用独立状态文件；状态为 running、succeeded 或 needs_confirmation 时不得盲目重复写入。
- 所有模式共用一个串行写入队列。先为当前批次预留唯一记录，再上传并回读；当前批次完成前禁止另一写入脚本同时选择空白记录。
- 图片数量、尺寸或接口成功不能代替内容验收；只有 [quality-gates.md](quality-gates.md) 通过后才能写入。
- 飞书控制台输出乱码不代表写入乱码；以 API 回读字段为准。
- 跨设备调用仓库 `scripts/feishu_delivery.py`，凭证只从本机环境变量或未纳入版本控制的 `.env` 读取。

## 漫画本地归档

漫画笔记在飞书写入并回读成功后，还要把最终发布图片归档到本机桌面 `漫画` 文件夹：

- 每篇漫画建立一个独立子文件夹，子文件夹默认使用最终发布标题；标题含 Windows 非法文件名字符时，删除非法字符，不改变标题含义。
- 只复制本篇最终交付图片，并按 `P01.png`、`P02.png`……顺序命名；图片数量以该篇实际页数为准。
- 不得归档测试旧版、失败版本、无字底图、参考图、人物圣经、提示词、联系表或状态文件。
- 本地图片顺序必须与飞书附件顺序完全一致。
- 若桌面 `漫画` 文件夹不存在，先告知用户创建；用户已明确授权 Codex 创建时可以代建。每篇子文件夹由 Codex 自动创建，无需用户逐篇创建。
- 飞书写入成功但本地归档失败时，保留飞书记录并如实说明归档状态；不得重复写入飞书。
